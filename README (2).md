## Colors

| Name | Hex | Use |
|---|---|---|
| Navy | `#12365B` | Primary: headings, buttons, top bar |
| River blue | `#5D99C9` | Secondary: eyebrows, accents, links on hover |
| Paper | `#FAF9F7` | Page background |
| Ink | `#1A1A1A` | Body text |
| Flame orange | `#E85A30` | Single accent only; never a fill |

## Usage rules

- Place the logo on white or paper backgrounds only, never on navy.
- Use flame orange sparingly — one accent per page.
- Photos are AI-generated illustrations of the fictional crew.
