# Finance folder

Read-only. Exports from Zoho Books, refreshed monthly by Carol.

- `Revenue history 24mo.csv` — twenty-four months. Bank balance is end of month.
- `AR aging.csv` — snapshot, not live. The ledger is the source of truth.
- `AP aging.csv` — open vendor bills. This is the source of truth for payables: Zoho Books (Free plan) has no Bills module, so open bills live here, not in the ledger. Paid bills are in Zoho as expenses.

Never edit a file here. If a number looks wrong, say so — do not correct it.
